# Acme Corp — Internet Usage Policy

## Acceptable Use

- Company network and VPN are for business purposes. Occasional personal use is allowed if it does not interfere with work.

## Prohibited

- Streaming piracy sites, cryptocurrency mining, and unauthorized peer-to-peer file sharing are prohibited.
- Do not disable endpoint security agents.

## Monitoring

- Acme may monitor traffic for security incidents. Personal passwords must never be reused on company systems.
